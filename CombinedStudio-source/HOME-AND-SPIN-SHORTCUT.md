# Home and global crosshair shortcut

Home opens first with PC performance, Audio, Customization and More tools collapsed. Home contains the dashboard and Game Library tabs. Game Library is absent from PC performance.

The shortcut defaults to Ctrl + Alt + R. Under Customization → Crosshair Studio → In-game randomizer shortcut, click the binding box, press a keyboard key or modifier combination, and release the primary key to save automatically. No key list or Apply button is required. Single keys, punctuation, numpad and Ctrl/Alt/Shift/Win combinations are supported. Escape or loss of focus cancels recording. Occupied/reserved combinations display an error beside the box and retain the previous binding. The application's own spin and overlay-toggle bindings are suspended only during recording, then restored. Key and modifiers persist across restarts.

In-game shortcuts now use a synchronous immediate change path: no carousel, animation delay, network transfer or awaiting another spin. Each press supersedes a pending animated spin and excludes the current ready design. It enables the click-through overlay without activating or restoring the main window. The normal on-page SPIN button retains its animation duration.

Community designs download and validate in the background, including checking that resting layers visibly render in the overlay area. A bounded ready set rotates in additional catalog uploads. Prepared frozen drawings/PNG data are reused rather than decoded on each shortcut press. The hotkey uses ready designs from the selected category; if none are available or there is no different ready choice, it immediately uses a generated crosshair while community designs prepare. This fallback avoids blank/unchanged results caused by unsupported uploads or waiting for the Internet. Community animation and exclusive-fullscreen limitations remain as documented elsewhere.

Validation: single-key and modifier-combination recording, automatic save on release, Escape cancellation, persistence, native global hotkey dispatch with the page hidden and the window minimized, ten repeated presses with a six-second animation setting, thirty switches between two real prepared community designs, and cancellation of an older carousel spin. Immediate-path assertions require every tested press to change the design synchronously within 250 ms. The checks are isolated; they do not modify the user's bindings or presets.
